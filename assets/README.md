# Static Assets Directory

Place your static image assets, icons, sample satellite GeoTIFF files, and sample test masks in this directory.

### Suggested Asset Structure:
- `assets/icons/` — SVG and icon assets for map layers and status HUD
- `assets/samples/` — Sample Sentinel-1 SAR and Sentinel-2 optical imagery files (`.png`, `.jpg`, `.tif`) for quick testing
- `assets/overlays/` — Pre-rendered raster or vector flood masks
